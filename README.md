# Myší skok (HraMysak)

Běhací hra pro mobil i počítač. Myšák běží kuchyní, přeskakuje pastičky, bedny a sklenice a sbírá sýr.

Celá hra je v jednom souboru `index.html`. Nic se neinstaluje, stačí ho otevřít v prohlížeči nebo zveřejnit přes GitHub Pages.

## Ovládání

| Akce | Mobil | Počítač |
| --- | --- | --- |
| Skok | klepnutí | mezerník / šipka nahoru / W |
| Vyšší skok | podržet prst | podržet klávesu |
| Dvojskok | klepnout znovu ve vzduchu | stisknout znovu ve vzduchu |
| Den / noc | tlačítko se sluncem / měsícem | klávesa N |
| Oblečení | výběr na úvodní obrazovce | klávesa O |

## Pravidla

- Body přibývají s uběhnutou vzdáleností, každý sýr dává +10 bodů.
- Hra postupně zrychluje a od 150, 250 a 400 bodů přibývají těžší překážky.
- Rekord, oblečení, den/noc a zvuk si hra pamatuje v prohlížeči.

## Oblečení

Hrdina, Myšák, Kuchař, Pirát, Ninja a Kosmonaut.

## Spuštění

Otevři `index.html` v prohlížeči. Pro zveřejnění zapni v nastavení repozitáře **Settings → Pages** zdroj „Deploy from a branch“ s větví `main` a složkou `/ (root)`.
